# MEAN Stack Career Playground

Four letters. One language. A whole career.

A playful, responsive landing page that explains MEAN stack development in plain words. It covers MongoDB, Express.js, Angular and Node.js, lets visitors watch a single request travel through the whole stack, lays out a beginner friendly roadmap, and points learners to guided bootcamps, courses and handpicked guides.

## What is inside

A bold, colourful neo brutalist design with thick outlines, hard shadows and sticker style cards, built to stop the scroll and still stay easy to read.

A sticky header with a mobile menu, a hero section with floating MEAN tiles, a moving ticker of technologies, four character cards for the tools in the stack, an interactive request journey, a four level learning roadmap, career role chips, program cards, guide cards, an FAQ section, a call to action band and a full footer.

Everything is pure HTML, CSS and a little vanilla JavaScript in a single file. There is no build step, no framework and no dependency apart from two Google Fonts, and the page falls back to system fonts if they cannot load.

It is fully responsive, keyboard friendly, and respects the reduced motion setting on visitors' devices.

## Try it locally

Download or clone the repository and open `index.html` in any modern browser. That is all.

## Publish it with GitHub Pages

1. Push the files to a new GitHub repository.
2. Open the repository on GitHub and go to Settings, then Pages.
3. Under Build and deployment, choose Deploy from a branch.
4. Select the main branch and the root folder, then save.
5. After a minute, your page will be live at `https://YOUR-USERNAME.github.io/mean-stack-career-playground/`.

## Make it your own

All colours live in the `:root` block at the top of the style section in `index.html`. Change the values of `--green`, `--yellow`, `--pink`, `--blue` and `--orange` to give the whole page a new mood in seconds.

To swap a link, search for its address in `index.html` and replace it. Every link opens in a new tab with safe `rel` attributes already in place.
